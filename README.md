## 🎯 我们的目标

这份任务并非考验你的技术深度，而是为了**模拟一次真实的项目协作**。通过它，我们希望能看到：

1.  你具备**自主学习和解决问题**的能力（比如，如何完成下面的每一步）。
2.  
3.  你掌握了现代软件开发的**基本协作工具**——Git & GitHub。


最终，`main` 主分支将会收集所有成功提交的同学的简历，这将是你们加入团队的第一次“开发”！

---

## 🚀 “Hello World” - 你的第一次代码贡献（5步指南）

>  在开始前，请仔细阅读每一步的目标。

| 步骤 | 操作指引 | |
| :--- | :--- | :--- |
| **1️⃣ Fork** | 点击仓库右上角的 **"Fork"** 按钮，将这个项目“复刻”一份到你自己的 GitHub 账号下。这是你的个人“副本”，你可以在上面自由修改。 | 
| **2️⃣ Clone** | 在你**自己的电脑**上，使用 `git clone [你Fork后仓库的URL]` 命令，将代码下载到本地。现在，你可以开始准备修改文件了。 |  |
| **3.5️⃣ 新建简历文件** | 在本地的代码文件夹里，进入 `resumes` 目录，按照下面的简历模板，**新建一个属于你自己的 Markdown 文件**。文件名格式为：`你的名字拼音.md` (例如: `zhangsan.md`)。 |  |
| **4️⃣ 提交与推送** | 在本地完成以下 Git 操作，将你的简历文件“保存”并“上传”到你 Fork 的仓库中：<br>1. `git add .` (或 `git add resumes/你的文件名.md`) <br>2. `git commit -m "feat: Add resume for [你的名字]"` <br>3. `git push origin main`  |  |
| **5️⃣ 发起 Pull Request (PR)** | 回到你 Fork 后的 GitHub 仓库页面，你会看到一个黄色的提示条，点击 **"Contribute"** -> **"Open pull request"**。按照指引，创建一个发往**“原始仓库”**的 PR。这是在请求我们将你的修改合并到主项目中来。 |  |

```
